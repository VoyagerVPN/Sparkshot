Sparkshot for Windows x64

Getting started

Extract the archive to a writable folder and run Sparkshot.exe. Drag to select
part of your screen. Press Ctrl+C to copy the selection, Ctrl+S to save it as
a PNG, or Esc to cancel. Sparkshot stays in the notification area.

Press Ctrl+Alt+S to start another capture. Right-click the Sparkshot tray icon
and choose Settings to change the shortcut, save folder or interface language.

Updating an existing copy

Choose Exit from the Sparkshot tray menu. Copy the new Sparkshot.exe into your
existing Sparkshot folder and launch it. Keep the data folder alongside the EXE
to preserve your shortcut, save folder, language and custom colors.
