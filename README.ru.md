# Sparkshot

<img src="assets/Sparkshot.svg" alt="Логотип Sparkshot" width="64">

[English](README.md) · **Русский**

Портативная программа для захвата и разметки снимков экрана на Windows x64.

[Собрать Sparkshot](#сборка-из-исходников)

## Быстрый старт

1. Запустите `Sparkshot.exe` и начните захват через значок программы в области уведомлений Windows.
2. Выделите область мышью. Добавьте пометки с помощью панели редактора, затем нажмите **Копировать** или **Сохранить**.

В настройках можно назначить клавишу захвата, выбрать папку для PNG и переключить язык.

## Инструменты редактора

- **Рисование:** карандаш, линия, стрелка, прямоугольник, эллипс и заливка.
- **Разметка:** текст, нумерация и пикселизация.
- **Правки:** ластик, пипетка с увеличением, отмена и повтор.

Выделение можно двигать и менять в размере. **Ctrl + Z** отменяет правку, **Ctrl + Y** или **Ctrl + Shift + Z** повторяет её. Sparkshot нумерует PNG и сохраняет предыдущие снимки.

## Сборка из исходников

Установите Visual Studio 2026 Build Tools в стандартную папку. Выберите MSVC x64, Windows SDK, CMake и Ninja.

```cmd
build.cmd
```

Запустите `.cache/build/Sparkshot.exe`.
