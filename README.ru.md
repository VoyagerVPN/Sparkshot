## Быстрый старт

1. Соберите и запустите `Sparkshot.exe`.
2. Откройте Sparkshot через трей Windows и запустите захват. В настройках можно выбрать клавишу захвата, папку сохранения и язык интерфейса.
3. Выделите область, добавьте пометки и скопируйте или сохраните снимок.

Выберите **English / Русский** в настройках. Выбор сохраняется в `data/settings.ini` рядом с EXE. При первом запуске приложение использует русский на русской Windows и английский в остальных случаях. Язык системного диалога выбора папки зависит от ресурсов Windows.

## Возможности

- Редактор выделенной области с линиями, стрелками, текстом, нумерацией, фигурами и пикселизацией.
- Пипетка с увеличением, отмена на **Ctrl + Z** и повтор на **Ctrl + Y** или **Ctrl + Shift + Z**.
- Копирование в буфер и сохранение пронумерованных PNG без перезаписи существующих снимков.
- Запуск из EXE и автозапуск по желанию.

## Сборка из исходников

Нужны Visual Studio 2026 Build Tools с MSVC x64, Windows SDK, CMake и Ninja. Скрипт использует стандартный путь установки Build Tools.

```cmd
build.cmd
```

Запустите `.cache/build/Sparkshot.exe`. Установщик и отдельный Visual C++ Runtime не нужны.

Для проверки ресурсов локализации:

```cmd
build.cmd build-l10n SparkshotLocalizationTest
.cache\build-l10n\SparkshotLocalizationTest.exe
```
